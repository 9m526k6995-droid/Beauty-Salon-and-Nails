# Beauty Salon & Nails – Website

Website für das Nagelstudio **Beauty Salon & Nails** in Passau (Inhaberin Huong Pham).

- `PROMPT.md`: kompletter Auftrag für Claude Code (Inhalte, Design, Technik, Deployment)
- `src/assets/bilder/`: aufbereitete Bilder (Logo, Studio, Farbkarten, Galerie)

Stack: Astro + Tailwind, Deployment über GitHub → Cloudflare.
